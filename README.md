# MyWebsite - Event Management Website

This is a web-based event management website where users can explore events and register for them.

## Features
- Event listing
- Event details page
- User registration
- Responsive website layout

## Technologies Used
- PHP
- HTML
- CSS
- JavaScript
- MySQL
- Bootstrap

## How to Run

1. Clone the repository
git clone https://github.com/strange60/MyWebsite.git

2. Move the project folder to XAMPP htdocs

3. Start Apache and MySQL

4. Open in browser
http://localhost/MyWebsite
